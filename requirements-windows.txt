# =============================================================================
# Power Market Intelligence Agent - Dependances Windows natif (sans Docker)
# =============================================================================
# Un seul environnement virtuel (.venv) pour backend + frontend.
# Toutes les versions ci-dessous disposent de wheels precompilees win_amd64
# pour Python 3.10, 3.11 et 3.12 : aucune compilation, aucun Visual C++ requis.
# Installe par setup.ps1 avec `pip install --only-binary :all:`.
#
# Python 3.13+ n'est PAS supporte (numpy 1.26 / pandas 2.2.1 n'ont pas de wheel).
#
# Differences volontaires par rapport a backend/requirements.txt :
#   - python-pptx 0.6.23 (au lieu de 0.6.21) : 0.6.21 n'a pas de wheel et
#     plante sur Windows/Python 3.10+ (AttributeError collections.abc, fix #762).
#   - psycopg2-binary / sqlalchemy / alembic retires : PostgreSQL n'est pas
#     utilise par le code (aucun import), c'etait un artefact de docker-compose.
#   - uvicorn[standard] : identique, uvloop est automatiquement exclu sous
#     Windows (marqueur d'environnement) ; le rechargement utilise watchfiles.
#   - pydantic 2.7.4 (aligne dans backend/requirements.txt) : 2.6.x plante sur
#     Python >= 3.12.4 (TypeError ForwardRef._evaluate ... recursive_guard).
# =============================================================================
