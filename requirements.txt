# =============================================================================
# Power Market Intelligence Agent - Dependances (backend + frontend)
# =============================================================================
# Un seul environnement virtuel (.venv) pour le backend FastAPI et le frontend
# Streamlit. Installe par setup.ps1 (Windows) / setup.sh (Linux, macOS) avec
# `pip install --only-binary :all:` : uniquement des wheels precompilees,
# aucune compilation, aucun compilateur C/C++ requis.
#
# Python supporte : 3.10, 3.11, 3.12 (64 bits). Python 3.13+ n'est PAS supporte
# (numpy 1.26 / pandas 2.2.1 / pydantic-core n'ont pas de wheel).
#
# Aucune base de donnees ni service externe : persistance sur fichiers
# (backend/generated, knowledge_base). Les APIs publiques (Energy-Charts,
# Open-Meteo) et les LLM sont optionnels (fallback local).
#
# Notes de versions :
#   - python-pptx 0.6.23 : 0.6.21 n'a pas de wheel et plante sur Python 3.10+
#     (AttributeError collections.abc, fix #762).
#   - pydantic 2.7.4 : 2.6.x plante sur Python >= 3.12.4
#     (TypeError ForwardRef._evaluate ... recursive_guard).
#   - uvicorn[standard] : uvloop est automatiquement exclu sous Windows
#     (marqueur d'environnement) ; le rechargement utilise watchfiles.
#
# Reproductibilite : les dependances transitives sont verrouillees dans
# constraints.txt (pip install -r requirements.txt -c constraints.txt), genere
# par scripts/update_constraints.py. Installation hors-ligne : voir
# scripts/make_wheelhouse.py et docs/INSTALLATION.md.
# =============================================================================
